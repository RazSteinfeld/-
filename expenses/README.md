# הכנסות והוצאות – אפליקציית PWA

אפליקציית PWA בעברית ומימין לשמאל לניהול הכנסות והוצאות, באותו מבנה כמו אפליקציית הנוכחות: קבצי HTML/JS רגילים, בלי Expo ובלי APK, בלי שרת. מארחים ב-GitHub Pages ומוסיפים למסך הבית, והיא נפתחת כמו אפליקציה רגילה, גם בלי אינטרנט.

**הנתונים נשמרים בטלפון בלבד** (`localStorage`). האפליקציה לא שולחת שום מידע החוצה, ואין בה אנליטיקס. הפונטים והאייקונים מצורפים לקוד.

## מה יש בה
| מסך | תוכן |
|---|---|
| סקירה | "כמה נשאר החודש", גרף מגמה חודשי, דונאט קטגוריות, בתי העסק הגדולים, תשלומים בדרך |
| תנועות | חיפוש, סינון, תיקון סיווג (גם לכל בית העסק), מחיקה |
| חיסכון | פוטנציאל חיסכון חודשי ושנתי, הזדמנויות עם צעדים מעשיים, השוואה לממוצע, מנויים |
| עוד | ייבוא קבצים, **ייצוא גיבוי JSON**, **שחזור מגיבוי**, הכנסה צפויה, מחיקת נתונים |

כללים שחשוב להכיר:
- **חיוב כרטיס אשראי בבנק לא נספר כהוצאה** (שורת "מקס איט / ישראכרט / כאל" בחשבון הבנק היא העברה), כדי שלא ייספר פעמיים עם פירוט הכרטיס. כך גם חיסכון והעברות פנימיות.
- **תשלומים:** משויכים לחודש לפי תאריך החיוב. תשלומים שעוד לא נגבו מוצגים ב"תשלומים בדרך".
- **חודשים חלקיים:** מסומנים "חלקי". בממוצעים ובבסיס החיסכון משתמשים בחודשים שלמים בלבד.
- **כפילויות:** אפשר לייבא קבצים חופפים או את אותו קובץ שוב. תנועה שכבר קיימת לא תוכפל.

## התקנה בטלפון (כמו אפליקציית הנוכחות)

1. **אירוח:** ב-GitHub: Settings ← Pages ← Deploy from branch, ובחר את הענף שבו נמצאים הקבצים (אותו ענף של אפליקציית הנוכחות) ואת התיקייה `/ (root)`.
2. **כתובת:** האפליקציה נמצאת באותה כתובת של אפליקציית הנוכחות, עם `/expenses/` בסוף. לדוגמה `https://razsteinfeld.github.io/-/expenses/`.
3. **התקנה:** פתח את הכתובת ב-Chrome בטלפון, לחץ על תפריט שלוש הנקודות (⋮) ובחר **"התקנת האפליקציה"** (או "הוספה למסך הבית"). האייקון "הכנסות והוצאות" יופיע במסך הבית.
4. **שימוש:** פתח את האפליקציה ← "ייבוא קבצים" ← בחר את קבצי ה-Excel/CSV מ-Max ומהבנק.

## גיבוי (חשוב)
נתונים בדפדפן יכולים להימחק אם מנקים נתוני אתר, מסירים את האפליקציה או מחליפים טלפון.
- **עוד ← ייצוא גיבוי** יוצר קובץ JSON עם כל הנתונים (שיתוף ל-Drive/מייל, או הורדה לקובץ).
- **עוד ← שחזור מגיבוי** טוען אותו בחזרה: מיזוג (מוסיף רק מה שחסר) או החלפה.
- האפליקציה מזכירה לגבות כשעבר יותר מחודש.

## עדכון האפליקציה
דוחפים את הקבצים החדשים ל-GitHub. ה-service worker טוען מהרשת קודם, ולכן הגרסה החדשה מגיעה בפתיחה הבאה (לפעמים צריך לסגור ולפתוח פעמיים). הנתונים נשארים. אם הוספת קובץ חדש לאפליקציה, הוסף אותו לרשימה ב-`sw.js` והעלה את `CACHE`.

## פיתוח
```
cd expenses
npm install
npm run build        # בונה את core.js (הלוגיקה + קורא ה-Excel) ואת קובץ האייקונים
npm test             # בדיקות: פירוק, סיווג, כפילויות, חודשים חלקיים, תשלומים, חיסכון, גיבוי
npm test -- path/to/max.xlsx path/to/bank.xlsx   # פירוק קבצים אמיתיים והדפסת סיכום
npm start            # שרת מקומי בכתובת http://localhost:8081
```
- `src/` – הלוגיקה ב-TypeScript. `core.js` הוא הפלט שלה, **והוא נשמר בגיט** כדי שלא יהיה שלב בנייה בשרת. אחרי שינוי ב-`src/` מריצים `npm run build` ומעלים גם את `core.js`.
- `app.js`, `style.css`, `index.html` – הממשק (JavaScript רגיל).
- אם קיימת תיקיית `samples/` (לא עולה לגיט), `npm test` יפרק גם את הקבצים שבה.

### הערה על פורמט הקבצים
הפירוק מזהה את שורת הכותרות לפי שמות העמודות ("תאריך עסקה", "שם בית העסק", "סכום חיוב", "חובה", "זכות" ועוד) ולא לפי מיקום. הוא נכתב ונבדק על קבצים שנוצרו לפי המבנה הידוע של Max ובנק מזרחי. אם קובץ אמיתי לא מזוהה, הרץ `npm test -- הקובץ.xlsx`, ושלח את שורת הכותרות כדי להוסיף את השמות החסרים ל-`SYNONYMS` ב-`src/parsers/table.ts`.
