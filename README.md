# נוכחות ושכר

אפליקציית PWA בעברית לדיווח כניסה/יציאה וחישוב שכר. בלי שרת ובלי הרשמה – הנתונים נשמרים בדפדפן שלך (`localStorage`) ועובדת גם בלי אינטרנט.

## מה היא עושה
- **כניסה / יציאה** בלחיצה, עם טיימר חי ושכר משמרת שמתעדכן בזמן אמת.
- **משמרת ידנית** – אם שכחת כניסה או יציאה: הוספה, עריכה ומחיקה של כל משמרת, כולל תצוגה מקדימה של השכר.
- **שכר לכל משמרת** – 44 ₪ לשעה, ו-150% מיום שישי 16:00 עד יום ראשון 04:00.
- **חגים** – מזוהים אוטומטית לפי הלוח העברי (ראש השנה, יום כיפור, סוכות, שמיני עצרת, פסח, שביעי של פסח, שבועות). התעריף המוגדל מתחיל בערב החג ב-16:00 ונמשך עד 04:00 אחרי החג. אפשר לבטל חג או להוסיף יום חג ידנית בהגדרות.
- **סיכום חודשי** – ברוטו ונטו, שעות רגילות מול שעות 150%, ופירוט ניכויים (מס הכנסה, ביטוח לאומי, ביטוח בריאות, פנסיה).
- **גיבוי** – ייצוא וייבוא JSON, וייצוא CSV לחודש.

## חישוב הנטו
הערכה לפי נתוני 2026: מדרגות מס הכנסה, נקודת זיכוי = 242 ₪ (ברירת מחדל 2.25 נקודות), ביטוח לאומי ובריאות במדרגה מופחתת עד 7,703 ₪, הפרשת פנסיה 6% עם זיכוי מס של 35%. אפשר לשנות נקודות זיכוי ואחוז פנסיה בהגדרות. תלוש השכר הוא המקור המחייב.
משמרת שייכת לחודש שבו היא התחילה. לא מחושבות שעות נוספות, נסיעות או בונוסים.

## הרצה והתקנה בטלפון
```
npm start        # שרת מקומי בכתובת http://localhost:8080
npm test         # בדיקות לחישוב השכר והמס
```
כדי להשתמש בטלפון צריך לארח את הקבצים בכתובת HTTPS (למשל GitHub Pages: Settings ← Pages ← Deploy from branch). לאחר מכן לפתוח את הכתובת בדפדפן ולבחור "הוסף למסך הבית" – היא תיפתח כמו אפליקציה רגילה.

> הנתונים שמורים רק במכשיר ובדפדפן שבהם הוזנו. מומלץ לייצא גיבוי מדי פעם מההגדרות.
