# נוכחות ושכר

אפליקציית PWA בעברית לדיווח כניסה/יציאה וחישוב שכר. בלי שרת ובלי הרשמה – הנתונים נשמרים בדפדפן שלך (`localStorage`) ועובדת גם בלי אינטרנט.

## מה היא עושה
- **כניסה / יציאה** בלחיצה, עם טיימר חי ושכר משמרת שמתעדכן בזמן אמת.
- **משמרת ידנית** – אם שכחת כניסה או יציאה: הוספה, עריכה ומחיקה של כל משמרת, כולל תצוגה מקדימה של השכר.
- **שכר לכל משמרת** – 44 ₪ לשעה, ו-150% מיום שישי 16:00 עד יום ראשון 04:00.
- **הוספה מהירה** – כפתור אחד למשמרת בוקר (06:00–14:00), בוקר מאוחר (08:00–16:00), ערב (14:00–22:00) או לילה (22:00–06:00), לתאריך שנבחר, עם ביטול.
- **אחוז שכר ידני** – בעריכת משמרת אפשר לקבוע שכל המשמרת תחושב ב-125%, 150% או 200% (במקום החישוב האוטומטי של שבת/חג).
- **חגים** – מזוהים אוטומטית לפי הלוח העברי (ראש השנה, יום כיפור, סוכות, שמיני עצרת, פסח, שביעי של פסח, שבועות). התעריף המוגדל מתחיל בערב החג ב-16:00 ונמשך עד 04:00 אחרי החג. אפשר לבטל חג או להוסיף יום חג ידנית בהגדרות.
- **סיכום חודשי** – ברוטו ונטו, פירוט שעות לפי אחוז שכר, ופירוט ניכויים (מס הכנסה, ביטוח לאומי, ביטוח בריאות, פנסיה).
- **גיבוי בענן** – שמירה אוטומטית ב-Gist פרטי בחשבון ה-GitHub שלך, סנכרון בין מכשירים ושחזור בטלפון חדש (ראה למטה).
- **גיבוי לקובץ** – ייצוא וייבוא JSON, וייצוא CSV לחודש.

## גיבוי בענן
הגדרה חד-פעמית: **הגדרות ← גיבוי בענן** (או הכפתור "הפעלה" בבאנר שבראש המסך).
1. יוצרים טוקן דרך הקישור באפליקציה (הרשאת `gist` בלבד, ובשדה Expiration בוחרים No expiration).
2. מדביקים אותו באפליקציה ולוחצים "התחברות".

מאותו רגע כל שינוי נשמר לבד כ-3 שניות אחריו, וגם בעת מעבר לאפליקציה אחרת. בטלפון חדש מתחברים עם אותו טוקן והנתונים חוזרים. אם יש נתונים בשני המכשירים הם מתאחדים: לכל משמרת יש זמן עדכון והגרסה החדשה מנצחת, מחיקות מסונכרנות, וההגדרות העדכניות מנצחות. אפשר לעבוד גם בלי אינטרנט והשינויים יישמרו בענן כשהחיבור חוזר.

הערות אבטחה:
- הנתונים נשמרים ב-Gist *secret*: הוא לא מופיע בחיפוש ובפרופיל, אבל מי שיש לו את הקישור המלא יכול לקרוא אותו. אל תשתף אותו.
- הטוקן נשמר רק בדפדפן של המכשיר, ונשלח רק אל `api.github.com`. כל האתרים תחת `razsteinfeld.github.io` חולקים אותו אחסון דפדפן, לכן אל תפרסמו שם קוד שאינו שלכם.
- לביטול: github.com/settings/tokens (מחיקת הטוקן), ו-"ניתוק" באפליקציה. היסטוריית הגרסאות של הנתונים נשמרת אצל GitHub ב-Gist.

## חישוב הנטו
הערכה לפי נתוני 2026: מדרגות מס הכנסה, נקודת זיכוי = 242 ₪ (ברירת מחדל 2.25 נקודות), ביטוח לאומי ובריאות במדרגה מופחתת עד 7,703 ₪, הפרשת פנסיה 6% עם זיכוי מס של 35%. אפשר לשנות נקודות זיכוי ואחוז פנסיה בהגדרות. תלוש השכר הוא המקור המחייב.
משמרת שייכת לחודש שבו היא התחילה. לא מחושבות שעות נוספות, נסיעות או בונוסים.

## הרצה והתקנה בטלפון
```
npm start        # שרת מקומי בכתובת http://localhost:8080
npm test         # בדיקות לחישוב השכר והמס
```
כדי להשתמש בטלפון צריך לארח את הקבצים בכתובת HTTPS (למשל GitHub Pages: Settings ← Pages ← Deploy from branch). לאחר מכן לפתוח את הכתובת בדפדפן ולבחור "הוסף למסך הבית" – היא תיפתח כמו אפליקציה רגילה.

> הנתונים שמורים רק במכשיר ובדפדפן שבהם הוזנו. מומלץ לייצא גיבוי מדי פעם מההגדרות.
